# RAG testing

Run `python -m pytest -q`. `tests/conftest.py` forcibly blanks S3, Qdrant and LLM endpoints/credentials before importing application settings; provider-specific tests use explicit fakes. This is necessary because Pydantic loads root `.env` by default. Cross-user tests exercise owner filters and PostgreSQL revalidation on SQLite, not PostgreSQL RLS. For live-service testing, use a separate explicit integration command/process, synthetic data, disposable PostgreSQL/S3/Qdrant resources, local model weights and written authorization; ordinary tests must not be pointed at production. The test suite does not claim actual AWS/Qdrant/Groq or real PostgreSQL RLS verification.
